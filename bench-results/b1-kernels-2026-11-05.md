# B1: kernel throughput (5 Nov 2026)

Raw output: [`b1-kernels-2026-11-05.txt`](b1-kernels-2026-11-05.txt). Machine: Apple M4, 10 cores, 16 GB RAM, macOS (one core).

```bash
cargo bench --bench kernels
```

Each iteration scores 65,536 random codes against one query's lookup tables (one large cluster). Codes/s is criterion's throughput (mean); GB/s is codes/s times the code size, 32 bytes at 256 dims and 64 at 512.

| Kernel | 256 dims: codes/s | GB/s  | 512 dims: codes/s | GB/s  |
| ------ | ----------------- | ----- | ----------------- | ----- |
| scalar | 46.3M             | 1.48  | 23.1M             | 1.48  |
| NEON   | 516.3M            | 16.52 | 257.1M            | 16.46 |

NEON is 11.1x scalar at both sizes. Against the PRD targets: at least 400M codes/s on NEON is met (516M); at least 20x scalar is not (11x). The scalar kernel is plain Rust, and the compiler vectorizes its adds, so it is a stronger baseline than a byte-at-a-time loop.

AVX2 and AVX-512 run on x86 only. Both are tested bit for bit against scalar (AVX2 in an x86 container here and on CI's ubuntu runner, AVX-512 under Intel SDE on CI); their throughput rows wait for the x86 cloud VM.
